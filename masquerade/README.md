# The Midnight Masquerade — concept case for ayamuse.com

Портфолио-концепт в `ayamuse-site/masquerade/` → адрес https://ayamuse.com/masquerade/

## Где что менять
- `config.js` — все тексты: строки приглашения, дресс-код, программа (время редактируемое), ссылка CTA, список событий.
- `style.css` — цвета и шрифты в самом начале (`:root`).
- `assets/` — видео (MP4 + JPG-постер с тем же именем), фото (JPG + WebP), шрифты (локальные, OFL).

## Посмотреть локально
В папке `site` выполнить `python -m http.server 8000` и открыть http://localhost:8000/masquerade/
(или просто открыть index.html в Chrome).

## Интеграция
1. Страница размещается вместе с остальным статическим сайтом из ветки `main`.
2. В `sitemap.xml` добавлен адрес; в #work на главной — 10-я карточка с отдельными desktop/mobile превью.
3. CTA ведёт на https://ayamuse.com/?ref=midnight-masquerade#contact — пробрасывает UTM-метки.
4. Аналитика: страница шлёт события `masquerade_view`, `enter_masquerade_click`, `invitation_revealed`,
   `invitation_saved`, `event_world_cta_click` в dataLayer / gtag / Plausible / Cloudflare Zaraz — если что-то из этого подключить.
5. Ссылки для соцсетей: `https://ayamuse.com/masquerade/?utm_source=pinterest&utm_medium=social&utm_campaign=masquerade`
   и `...utm_source=instagram...`.

## Проверка 12 октября 2026
- Убраны движущийся грейн и вспышки; оставлена слабая статичная фактура.
- Исправлены межстрочные интервалы, выносы каллиграфии, размеры заголовков и карточки приглашения.
- Портреты, танец, стол и гардеробная сохраняют исходные пропорции. На мобильном конверт и зал показаны целиком; фон первого экрана кадрируется под экран.
- Из коротких роликов удалены финальные склейки с двоением. Они проигрываются один раз при входе в область просмотра и останавливаются на чистом кадре. Фоновый ролик фасада остаётся циклическим.
- Проверены 320×568, 375×667, 390×844, 430×932, 768×1024, 844×390, 1024×768, 1440×900, 1920×1080 в Chromium: без горизонтального переполнения и выхода ключевого текста за границы.
- Проверены проявление письма, hover, персонализация (включая имя из 32 широких символов), скачивание PNG, UTM в CTA, prefers-reduced-motion, остановка видео вне экрана.
- RSVP работает только локально. Сервер регистрации и отправка имени отсутствуют.
- Основной контент продублирован в HTML для индексации и чтения без JavaScript. При изменении конфигурации нужно обновить соответствующий статичный HTML.
- События аналитики подготовлены, но внешний сборщик аналитики эта страница сама не подключает. Подключение/проверка конкретного счётчика и социальный запуск — отдельные задачи.
